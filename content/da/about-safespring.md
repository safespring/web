{{< about-section id="today" title="En svensk cloududbyder" class="about-editorial-today" >}}

Med Safespring kan I køre jeres software og lagre jeres data uden selv at skulle købe og vedligeholde servere. Til større projekter kan vi levere beregningsressourcer, lagring, Kubernetes og GPU-kapacitet samlet.

Safespring har hovedkontor i Solna. Bestyrelsesmedlemmerne og medarbejderne ejer virksomheden. Alle ejere er hjemmehørende i EU eller et andet EØS-land. [Vores medarbejdere]({{< relref "/contact.md" >}}#vores-medarbejdere) samarbejder med universiteter, offentlige myndigheder og virksomheder, også i regulerede brancher.

{{< /about-section >}}

{{< about-section id="story" title="Vores historie" class="about-editorial-story" >}}

{{% timeline ariaLabel="Safesprings historie" %}}
{{% timeline-item year="2014" title="Vores rødder i IPnett" %}}
IPnett Cloud begyndte at udvikle infrastruktur- og backuptjenester til akademiske miljøer i Norden.
{{% /timeline-item %}}
{{% timeline-item year="2016–17" title="Safespring bliver en selvstændig virksomhed" %}}
Safespring AB blev registreret i september 2016. I 2017 overtog virksomheden kunder, kontrakter, medarbejdere og driftssteder fra IPnett.
{{% /timeline-item %}}
{{% timeline-item year="2023" title="En del af European Open Science Cloud" %}}
Som underleverandør til Poznań Supercomputing and Networking Center (PSNC) var Safespring med i den gruppe, der vandt EOSC-udbuddet.
{{% /timeline-item %}}
{{% timeline-item year="2025" title="Adgang til cloudtjenester gennem OCRE 2024" %}}
Vores tjenester blev tilgængelige gennem rammeaftalen for forskning og uddannelse.
{{% /timeline-item %}}
{{% timeline-item label="I DAG" title="En bredere cloudplatform" %}}
Vi tilbyder beregningsressourcer, lagring og Kubernetes til forskningsmiljøer, erhvervslivet og den offentlige sektor. Vi står for driften af Kubernetes-kontrolplanet.
{{% /timeline-item %}}

{{< about-section id="infrastructure" title="Datacentre i Sverige og Norge" image="/img/graphics/safespring-cloud-sites-map-container.svg" publicCloud="Offentlig cloud" privateCloud="Privat cloud" alt="Kort over Safesprings driftssteder til offentlig og privat cloud i Stockholm, Oslo og Kalix." caption="Vores driftssteder for offentlig og privat cloud i Sverige og Norge." >}}

De driftssteder, hvor vi leverer beregningskapacitet, fungerer uafhængigt af hinanden. Skal en applikation være tilgængelig, selv om ét driftssted falder ud, kan I køre kopier af applikationen på forskellige driftssteder og styre trafikken mellem dem. I vores dokumentation kan I se, [hvilke tjenester der er tilgængelige på hvert driftssted](https://docs.safespring.com/#service-availability-by-site).

Vi samarbejder med [vores datacenterpartnere]({{< relref "/data-centers.md" >}}) om fysisk sikkerhed, strømforsyning, køling og netværksforbindelser. Anlæggene bruger strøm fra vedvarende energikilder. Overskudsvarmen fra datacentret Stockholm Norr bruges til fjernvarme.

{{< about-section id="research" title="Vores arbejde med forskning og uddannelse" class="about-editorial-research" image="/img/background/safespring-research.jpg" alt="" >}}

Forskere, der bruger [European Open Science Cloud]({{< relref "/industries/eosc.md" >}}), kan køre beregninger og containere på infrastruktur, som vi leverer som underleverandør til Poznań Supercomputing and Networking Center (PSNC).

Organisationer inden for forskning og uddannelse i Danmark, Norge og Sverige kan købe vores cloudtjenester gennem [GÉANTs rammeaftale OCRE 2024]({{< relref "/industries/research-and-education.md" >}}), hvis de er omfattet af aftalen.
